后端服务设置
链接解析 / 转写 / AI 分析需要后端转发（不存任何数据）。后端推荐部署在 Vercel（*.vercel.app，国内可直连）；地址填一次即记住。
添加节目
上传的音频文件保存在这台设备的浏览器里（IndexedDB），不会上传到任何服务器；转写时仅临时经过转写服务。解析不了的平台（如付费内容）也可用上传兜底。
数据备份
数据存在浏览器里，清除浏览器数据会让它们消失。定期「导出备份」存成文件；换设备时在新设备「导入备份」即可迁移（导入覆盖现有数据。备份不含本地上传的音频文件本体）。
